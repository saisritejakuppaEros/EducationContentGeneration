# Project Guidelines

* Place all executable Python scripts inside the `scripts/` directory using clear, descriptive filenames.
* Prioritize working, maintainable code over extensive comments or documentation.
* Avoid large docstrings unless they are necessary to explain non-obvious logic.
* Keep the codebase simple, readable, and easy to modify.

## Documentation

* Store all documentation in the `docs/` directory.
* Create one short Markdown file per module or major component.
* Each document should briefly describe:

  * What the module does.
  * Its primary purpose.
  * Any important inputs or outputs (if applicable).

Keep documentation concise—just enough to help someone quickly understand the module. Avoid detailed technical explanations unless explicitly requested.
